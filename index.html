Map Flow

2025

A web app that visualizes pathfinding on real city graphs with smooth, animated exploration and final-path highlights. The backend is a Python/Flask API that computes Dijkstra, A*, BFS, DFS, and bidirectional search, returning a compact JSON payload with the path and visit order. The frontend uses HTML5 Canvas with offscreen caching, precomputed node positions, and requestAnimationFrame to render neon-style glows and fast interactions on large maps. Performance is optimized with path‑only responses, gzip via Flask‑Compress, and a stateless design suited for serverless deployment on Vercel, cutting load times by 70%.

VHDL-CPU

2024

This project involves the design and implementation of a Simple Central Processing Unit (CPU) in VHDL for deployment on an FPGA board. The CPU is built with an Arithmetic Logic Unit (ALU) and a Control Unit to process and manage data operations. The system also integrates eight 8-bit registers, a finite state machine (FSM), and a 3x8 decoder to handle instruction processing. Additionally, user interaction is facilitated by a seven-segment display.

HCS12 Morse-Code-Flasher

2024

This project demonstrates a basic application of the HCS12 microcontroller (MCU), utilizing peripherals such as a keypad, 7-segment display, and an LCD to interact with Morse code input and output. The core functionality is the translation of user input, specifically the letter "A" on the keypad, into its corresponding Morse code sequence. The project includes both hardware-level and software-level features, with real-time interrupts (RTI) and key debounce mechanisms for smooth operation.
